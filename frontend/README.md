# Frontend: React.js + Vite

The frontend client for the **AI Digital Career Twin** platform.

### Planned Modules
- Student Authentication (Login / Register)
- Dynamic Student Profile & Portfolio
- Digital Career Twin Cockpit (3D/Radar Skill Mesh & "What-If" Simulation sliders)
- Placement Readiness & Expected Salary Gauges
- ATS Resume Analyzer & Entity Viewer
- Job Catalog & Skill Gap Heatmap
- Personalized Sprint Roadmap & Milestone Tracker
- Peer Percentile Benchmarking (against the 100k Base-Paper dataset)
